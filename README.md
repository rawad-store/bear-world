# 🐻 عالم الدب الصغير التعليمي

تطبيق ويب تعليمي تفاعلي للأطفال (PWA) يعمل دون اتصال، من إنتاج **مكتبة الرواد للطباعة والتصوير**.

## 📦 مكونات المشروع

| الملف | الدور |
|-------|-------|
| `index.html` | التطبيق كاملًا (HTML + CSS + JS) |
| `manifest.json` | إعدادات PWA (أيقونة، اسم، اختصارات) |
| `sw.js` | Service Worker — تخزين مؤقت واستخدام دون اتصال |
| `robots.txt` | توجيه محركات البحث |
| `sitemap.xml` | خريطة الموقع |
| `bear.png` | صورة الدب الرئيسية |
| `icon-192.png` | أيقونة PWA (192×192) |
| `icon-512.png` | أيقونة PWA (512×512) |

## ⚙️ متطلبات التشغيل

- متصفح حديث يدعم JavaScript وCanvas.
- اتصال بالإنترنت لأول تشغيل (لتحميل الخط من Google Fonts وملفات SW).
- بعد أول تشغيل: يعمل دون اتصال بالكامل.

## ▶️ التشغيل المحلي

```bash
# أي خادم HTTP بسيط:
python3 -m http.server 8080
# أو:
npx serve .
# ثم افتح: http://localhost:8080
